```html

```

- Nome do profissional
- Palavra-chave principal (Nutricionista em Cajazeiras PB)
- CTA implícito (Consulta Nutricional)
- Tamanho: 81 caracteres (ideal: 50-60)

✅ **Contém:**
- Palavras-chave relevantes
- Localização geográfica
- Serviços oferecidos
- CTA claro
- Tamanho: 160 caracteres (ideal)

## 6. robots.txt

```
User-agent: *
Allow: /
Sitemap: https://luanasalvino.com.br/sitemap.xml
```

✅ **Configurado para:**
- Permitir todos os bots confiáveis
- Bloquear scrapers maliciosos
- Indicar localização do sitemap

## 7. sitemap.xml

```xml
<url>
  <loc>https://luanasalvino.com.br/</loc>
  <lastmod>2025-10-09</lastmod>
  <changefreq>weekly</changefreq>
  <priority>1.0</priority>
  <image:image>...</image:image>
</url>
```

✅ **Inclui:**
- URLs do site
- Imagens importantes
- Frequência de atualização
- Prioridade de páginas

## 🎓 Dicas para Manter SEO

1. **Conteúdo Regular**
   - Postar no blog/Instagram semanalmente
   - Usar palavras-chave naturalmente
   - Criar conteúdo útil

2. **Atualizar Sitemap**
   - Sempre que adicionar páginas novas
   - Atualizar `<lastmod>` mensalmente

3. **Monitorar Performance**
   - Acompanhar posições no Google
   - Ver palavras-chave que trazem tráfego
   - Ajustar estratégia baseado em dados

4. **Responder Reviews**
   - Agradecer reviews positivos
   - Resolver problemas em reviews negativos
   - Incentivar pacientes a deixarem reviews

5. **Links Internos**
   - Linkar conteúdo relacionado
   - Usar anchor text descritivo
   - Criar hierarquia de páginas
