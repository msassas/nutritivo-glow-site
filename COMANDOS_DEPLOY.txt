# ==================================================
# 2. CRIAR REPOSITÓRIO NO GITHUB
# ==================================================

# Vá em: https://github.com/new
# Nome: nutritivo-glow-site
# Deixe PRIVADO
# NÃO marque "Add README"
# Criar repositório

# Depois, execute (substitua SEU_USUARIO pelo seu usuário do GitHub):
git remote add origin https://github.com/SEU_USUARIO/nutritivo-glow-site.git
git branch -M main
git push -u origin main

# - Build Command: (vazio)
